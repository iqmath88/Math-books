# ريلز السبورة

أمثلة من الكتاب مشروحة خطوة خطوة بأسلوب السبورة الطباشيرية. تُعرض حيّة داخل التطبيق
(`v2__reels__player.html#cone` و `#ladder`) وتُصدَّر فيديو ريلز 1080×1920.

| الملف | ما فيه |
|---|---|
| `chalk.js` | المحرك المشترك: السبورة، ملمس الطباشير، الكتابة التدريجية، الرياضيات باليد (الكسور، الأسس، π ≈ ⇒ θ مرسومة)، الخطوط والدوائر |
| `cone.js` | مثال 5 ص 95 (المرشح المخروطي) |
| `ladder.js` | مثال 4 ص 94 (السلم) |
| `steps.js` | الدرس 3−8 ص 140: فكرة الموضوع وخطوات الحل (نص الكتاب، المماس الأفقي، طريقة العمل، اختبار المشتقة الثانية، مثال سريع) |
| `box.js` | مثال 2 ص 141 (أكبر صندوق: قيمة عظمى) — مجسّم ثلاثي الأبعاد يُقص ويُثنى، ومنحني الحجم |
| `player.html` | المشغّل: تشغيل/إيقاف، مشهد سابق/تالٍ، شريط زمن بعلامات المشاهد، قائمة المشاهد، ملء الشاشة، كتم الصوت |
| `reels.css`, `fonts/` | الخطوط: الرقعة (العناوين)، مرهي (نص الكتاب)، Caveat (الرياضيات) |
| `audio/` | موسيقى كل مثال (تولَّد برمجياً: `tools/reels/music_*.py`) — لا تُخزَّن للعمل دون إنترنت؛ بدونها يعمل المشغّل بساعته |

## قواعد كل ريلز
- **نص المثال حرفياً** من الكتاب بعد سؤال العصف الذهني، مع رقم الصفحة واسم الأستاذ.
- **كل رقم ومستوى في الرسم محسوب من معادلات الكتاب**؛ الإطار عند الزمن t لا يعتمد إلا على t (حتمي).
- الاشتقاق **عملية بعد عملية**: السطر الحالي كبير، والسابق باهت فوقه.
- أثناء الحل يتوقف المشهد عند «لحظة» السؤال (مثل h = 12)؛ ويُكتب على الشاشة كل تسريع أو إبطاء للزمن.
- أي إضافة ليست من الكتاب (المفارقة، سؤال التعليقات) تُبنى على القانون نفسه.

## إضافة مثال جديد
1. انسخ `ladder.js` إلى `<id>.js`، وغيّر الرسم والمشاهد ونص الكتاب (`BOOK`) وأسماء المشاهد (`NAMES`)، وسجّله `window.REELS.<id>`.
2. أضفه في `player.html` (وسم `<script>`، وزر في «اختر المثال»، و`<audio id="a-<id>">`) وفي بطاقات `index.html` وقائمة `CORE` في `sw.js`.
3. الموسيقى: انسخ `tools/reels/music_ladder.py` وعدّل أزمنة المشاهد، ثم حوّلها: `ffmpeg -i m.wav -c:a aac -b:a 128k audio/<id>.m4a`.
4. `node tools/flatten.cjs` ثم `node tests/reels.test.cjs`.

## تصدير فيديو ريلز
```bash
node tools/flatten.cjs
python3 tools/reels/music_cone.py /tmp/cone.wav
node tools/reels/render.cjs cone out/Nibor_Cone_Ex5_p95_Reels.mp4 /tmp/cone.wav
```
