# صيغة الدرس في المحرك (v2)

كل فصل = ملف `v2/<id>.js` يعرّف `window.BOOK = {id, grade, chapter, title, desc, classic, S, G, src}`:
- `S` المشاهد (الرسوم التفاعلية)، `G` مولّدات «تمرين مشابه»، `src` نص الدروس بالصيغة أدناه.
- المحرك `v2/engine.js` يقرأ `src` ويبني الصفحات؛ **إضافة درس لا تحتاج تعديل المحرك**.

## البنية

```
=== id | رقم البند | العنوان | الصفحات | وصف قصير        ← درس جديد
--- @stage عنوان القسم                                   ← قسم (المرحلة اختيارية)
>>> scene #1 ! + .book :: تسمية                           ← خطوة يتبعها الرسم «scene»
```

**المراحل الست** (`@stage`): `discover` اكتشف · `understand` افهم · `try` جرّب · `learn` تعلّم الحل · `practice` تدرّب · `check` تحقّق.
تظهر شريطاً أعلى الدرس، وتُقفز إليها بالمفاتيح 1–6. يجوز إسقاط مرحلة لا تناسب البند.

**نوع المحتوى** (على سطر `>>>`): `.book` من الكتاب · `.extra` شرح إضافي · `.act` نشاط تفاعلي · `.enr` تمرين إثرائي (ليس من الكتاب).

علامات أخرى على سطر `>>>`: `#n` رقم الخطوة، `!` نتيجة، `+` فاصل، `:: نص` تسمية.

## أجزاء الخطوة

| السطر | المعنى |
|---|---|
| `k:` `h1:` `h2:` `p:` `lead:` | عنوان صغير، عناوين، فقرة |
| `$$ …` | معادلة في سطر مستقل (TeX) |
| `- …` | قائمة |
| `law: عنوان` ثم أسطر `\| …` | تعريف/مبرهنة/قانون من الكتاب |
| `note:` / `err:` | ملاحظة / تنبيه على خطأ في الكتاب |
| `xp: عنوان` ثم `\| …` | **خطوة توضيحية إضافية** (ليست من الكتاب) |
| `tnote:` | ملاحظة للمدرّس (تظهر في وضع المدرّس فقط) |
| `let: نفرض` ثم أسطر `\| رمز ; المعنى ; القيمة` | جدول «نفرض» لترتيب المعطيات (يُوسم «توضيح») |
| `rel: نص` | العلاقة الرئيسة في إطار؛ إن بدأ النص بـ `» ` وُسم «توضيح» (ليس من الكتاب) |
| `tbh:` / `tbl:` | صف عنوان / صف جدول، الخلايا بـ `\|` |
| `ask:` + `o:` / `o*:` + `why:` | سؤال اختيار (`o*` الصحيح) |
| `prac: الجواب ; تلميح الخانة` | تمرين يُصحَّح آلياً (أعداد، كسور، √، π، ln، e، نقاط) |
| `self:` | تمرين بحل ذاتي (للأجوبة الجبرية) |
| `hint:` | تلميح متدرّج (يتكرر) |
| `miss: جواب خاطئ ; رسالة` | تشخيص خطأ شائع |
| `gen: اسم` | زر «تمرين مشابه» من `G[اسم]` |
| `sol:` ثم `\| …` | الحل؛ السطر الذي يبدأ بـ `» ` يُوسم «توضيح» |
| `ok: scene` | مشهد يُعرض بعد الإجابة الصحيحة |

داخل النص: `$tex$`، `**غامق**`، `[[tan:نص ملوّن]]` (الألوان: f, chord, tan, c, int).
داخل TeX: `\cf{} \cch{} \ctn{} \ccc{} \cin{}` لتلوين الرموز بألوان الرسم.

## الوضعان
- **طالب** (افتراضي): حل التمرين يُفتح بعد محاولة أو بعد استنفاد التلميحات؛ ملاحظات المدرّس مخفية.
- **مدرّس**: الحلول تُفتح مباشرة، وملاحظات المدرّس ظاهرة. يُحفظ الاختيار على الجهاز.

## وسوم «وزاري» (سنوات الامتحانات الوزارية)
- في **وضع المدرّس** يظهر زر «＋ وزاري» تحت عنوان كل مثال وتمرين: اكتب السنة (مثل 2013) واختر الدور ثم «حفظ». الحذف بزر × على الوسم.
- ما يضيفه المدرّس يُحفظ على جهازه فوراً (localStorage: `lb-tags-<id>`).
- **النشر للطلاب**: الصفحة الرئيسة للفصل (وضع المدرّس) ← «نسخ الوسوم»، ثم يُدمج النص في `v2/tags.json` على GitHub.
  الملف يُقرأ من الشبكة في كل فتح (غير مخزّن في ذاكرة التطبيق)، فيصل التعديل للطلاب دون إصدار جديد؛ وتُحفظ آخر نسخة للعمل دون اتصال.
- الصيغة: `{"g12c3": {"rates-3-0": [{"y":"2013","d":"الدور الثاني"}]}}` — المفتاح `درس-قسم-خطوة` (يظهر في `data-key` على الخطوة).
  تنبيه: إعادة ترتيب أقسام الدرس أو خطواته تغيّر المفاتيح، فتُراجع الوسوم بعدها.
- الصفحة الرئيسة للفصل تعرض «أسئلة وزارية في هذا الفصل» مرتبة من الأحدث، وكل سطر يفتح السؤال مباشرة (`#l=<درس>&k=<مفتاح>`).

## قالب خطوات الحل (المعدلات المرتبطة)
نفرض (`let:`) ← العلاقة في إطار (`rel:`) ← نشتق الطرفين بالنسبة لـ $t$ ← نعوّض (خطوة مستقلة) ← فحص الوحدات (`xp:`) ← معنى الإشارة (`xp:`).
نص الكتاب يبقى كما هو؛ كل ما يضيفه القالب موسوم «توضيح».
