# Math-books v1.5.0 — Stage 2: guided explanation

- Added four-step teaching guide: observe, explore, infer, apply.
- Teacher-facing prompts are generic and do not modify the mathematics or solutions.
- Added optional click-to-highlight for a diagram, equation or section.
- Touch-sized controls, collapsible guide and RTL support.
- Guide is only visible in interactive-board mode and closes when returning to reading.
- All chapter pages, icons, offline precache and single-folder ZIP retained.

Limitations: This is a guided teaching overlay, not chapter-specific mathematical step parsing or automated solution reveal. Browser/device testing still required.
