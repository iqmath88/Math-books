# فيديوهات يوتيوب الطويلة (1920×1080) بأسلوب السبورة

تستعمل محرك ريلز السبورة نفسه (`v2/reels/chalk.js`) بعد ضبط `CHALK_W=1920, CHALK_H=1080`.
كل حلقة صفحة HTML وملف JS يعرّف `window.EPISODE = {render(t), D, chapters}`؛ الإطار عند t لا يعتمد إلا على t.

| الملف | ما فيه |
|---|---|
| `optim/ep1.html`, `optim/ep1.js` | تطبيقات عملية على القيم العظمى أو الصغرى — الحلقة الأولى (الفكرة، خطوات الحل، أمثلة 1 و2 و4 · ص 140–143) — 12:25 |
| `optim/ep2.html`, `optim/ep2.js` | الحلقة الثانية (أمثلة 3 و5 و6 · ص 142–146، والخلاصة) — 11:52؛ تعتمد `lib.js` |
| `lib.js` | الأدوات المشتركة للحلقات: الفقرات، لوح الاشتقاق، الرسوم البيانية، بطاقة المثال ونص الكتاب، الإطار الكامل |
| `render.cjs` | التصدير إطاراً إطاراً على أجزاء متوازية (`JOBS`، افتراضياً 4) ثم الدمج مع الموسيقى |
| `music_bed.py` | موسيقى خلفية هادئة منخفضة المستوى تتغير مع بدايات الفصول |

```bash
# أزمنة بدايات الفصول من EPISODE.chapters
python3 tools/video/music_bed.py /tmp/ep1.wav 745 25 65 115 140 185 240 265 360 525 690
node tools/video/render.cjs tools/video/optim/ep1.html out/Optim_Ep1.mp4 /tmp/ep1.wav
```
للنظر إلى لحظة واحدة: افتح `optim/ep1.html?t=372`.
